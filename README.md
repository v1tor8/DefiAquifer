# DefiAquifer

Hydrological modeling and real-time processing enabled by Geo-optimized machine-learning algorithms and predictive Aquifer Manager.

The key benefits of using DefiAquifer include:

- Hydrological modeling and real-time processing
- enabled by Geo-optimized machine-learning algorithms
- and predictive Aquifer Manager

## Technology Stack

- typescript
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/DefiAquifer.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

DefiAquifer is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
